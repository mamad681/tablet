# Tablet Link — راهنمای راه‌اندازی

پنل شخصی برای دیدن **لوکیشن دقیق**، **نمایش صفحه** و **کنترل** تبلت اندرویدِ خودت، با جفت‌سازی QR.
فقط برای دستگاهی که مال خودت است؛ اپ اندروید برای شروع، اجازه‌ی صریح روی خود تبلت می‌خواهد.

## چه چیزی چه کاری می‌کند؟

| قابلیت | با صفحه‌ی وب (بعد از اسکن QR) | با اپ اندروید |
|---|---|---|
| لوکیشن دقیق (GPS) | ✅ (تا وقتی صفحه باز و روشن است) | ✅ (در پس‌زمینه هم) |
| پیام / بوق برای پیدا کردن تبلت | ✅ | ✅ |
| دیدن صفحه‌ی تبلت | ❌ (مرورگر موبایل اجازه نمی‌دهد) | ✅ |
| کنترل (تپ، سوایپ، Back/Home/Recents) | ❌ | ✅ |

## ۱) دیپلوی روی Railway

1. پوشه‌ی پروژه را (همین‌جا که `server.js` هست) روی یک ریپوی GitHub بگذار، یا از `railway up` استفاده کن.
2. در Railway: **New Project → Deploy from GitHub repo**.
3. در **Variables** این را اضافه کن:
   - `ADMIN_PASSWORD` = یک رمز قوی (الزامی؛ ورود به پنل با آن است)
   - اختیاری: `TOKEN_SECRET` = یک رشته‌ی تصادفی بلند (برای امضای توکن QR)
4. در **Settings → Networking → Generate Domain** یک دامنه بساز.
5. آدرس را باز کن، با `ADMIN_PASSWORD` وارد شو.

> اگر `ADMIN_PASSWORD` را نگذاری، سرور یک رمز موقت می‌سازد و در Logs چاپ می‌کند (برای هر اجرای جدید عوض می‌شود).

## ۲) جفت‌سازی با QR

1. در پنل: **ساخت QR** را بزن.
2. با دوربین تبلت اسکن کن و لینک را در **Chrome** باز کن.
3. در صفحه‌ای که باز می‌شود **شروع اشتراک لوکیشن** را بزن و اجازه‌ی لوکیشن بده → روی نقشه‌ی پنل می‌بینی.

## ۳) دیدن و کنترل صفحه (اپ اندروید)

پوشه‌ی `android/` یک پروژه‌ی Android Studio است.

1. Android Studio را باز کن → **Open** → پوشه‌ی `android`.
2. اجازه بده Gradle sync شود، بعد **Build → Build APK(s)**.
3. فایل APK را روی تبلت نصب کن (اجازه‌ی «نصب از منبع ناشناس»).
   - برای راحتی می‌توانی APK را با نام `app.apk` در پوشه‌ی `public/` بگذاری و دوباره دیپلوی کنی؛ آن‌وقت صفحه‌ی QR تبلت دکمه‌ی دانلود هم نشان می‌دهد.
4. QR را اسکن کن و در صفحه‌ی وب **باز کردن اپ Tablet Link** را بزن؛ سرور و توکن خودکار پر می‌شوند.
   (یا دستی: آدرس سایت و توکن — بخش آخر لینک `/t/<token>` — را در اپ وارد کن.)
5. در اپ اجازه‌ی لوکیشن و **ضبط صفحه** را تأیید کن.
6. **کنترل:** در اپ «فعال‌سازی کنترل (Accessibility)» → Tablet Link Control را روشن کن.
   - روی Samsung/اندروید ۱۳+ اگر خاکستری بود: تنظیمات ← برنامه‌ها ← Tablet Link ← ⋮ ← **Allow restricted settings**، بعد دوباره روشن کن.
7. در پنل **▶ نمایش صفحه** را بزن. روی تصویر کلیک = تپ، کشیدن = سوایپ.

## امنیت

- ورود به پنل با `ADMIN_PASSWORD`؛ کوکی HttpOnly + محدودیت تعداد تلاش ورود.
- توکن QR امضاشده (HMAC) است؛ بدون آن هیچ دستگاهی نمی‌تواند وصل شود. با عوض کردن `ADMIN_PASSWORD`/`TOKEN_SECRET` همه‌ی توکن‌های قبلی باطل می‌شوند.
- سرور فقط پیام‌ها را رد و بدل می‌کند و تصویر/لوکیشن را ذخیره نمی‌کند (فقط آخرین لوکیشن در حافظه می‌ماند).
- هر وقت خواستی در اپ **قطع اتصال** را بزن؛ نوتیفیکیشن دائمی هم نشان می‌دهد که اتصال فعال است.

## محدودیت‌ها و نکات

- کد اندروید اینجا کامپایل نشده (SDK اندروید در محیط ساخت نبود). سرور و رله‌ی پیام‌ها کامل تست شده؛ اپ را باید یک بار در Android Studio بسازی و روی تبلتت امتحان کنی. اگر خطای build دیدی متنش را بفرست تا درست کنم.
- بعضی اپ‌ها (بانکی، DRM مثل Netflix) صفحه‌ی خود را سیاه نشان می‌دهند؛ این محدودیت خود اندروید است.
- اگر تبلت را بچرخانی، تصویر بعد از حدود یک ثانیه با جهت جدید تنظیم می‌شود.
- ارتباط تصویر از طریق سرور Railway می‌گذرد؛ سرعت به اینترنت هر دو سمت بستگی دارد (حدود ۶ فریم در ثانیه).
- ذخیره‌ی pairing ها در حافظه است؛ بعد از ری‌دیپلوی لیست دستگاه‌ها خالی می‌شود، اما QR/توکن قبلی معتبر می‌ماند و دستگاه با همان توکن دوباره وصل می‌شود.
